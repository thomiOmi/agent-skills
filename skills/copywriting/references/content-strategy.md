# Content Strategy

Load this reference when planning public-facing content across channels: blog posts, email campaigns, social posts, newsletters, brand voice, or microcopy. Use it with `copywriting`; it carries the planning layer that the main skill's formulas assume.

## Examples

**Before (vague, no audience):**

> "Our platform helps businesses streamline their workflow."

**After (specific, audience-focused, value-driven):**

> "Stop chasing receipts. AutoCat logs every mileage, categorizes every expense, and generates your tax report in one click. Built for freelancers who bill by the mile."

## Core Principles

1. **Know the audience** - write for a specific reader, not everyone
2. **Clear over clever** - clarity always wins over wordplay
3. **Value first** - every piece of content must provide measurable value
4. **Consistent voice** - brand tone is consistent across all channels
5. **Measurable goals** - every campaign has a clear success metric

## Content Types

**Blog post:** Problem to context to solution to key takeaways to CTA
**Landing page:** Headline to value prop to proof to benefits to CTA
**Email:** Subject line to greeting to single message to CTA to closing
**Social:** Hook to value to link or visual to CTA, within the character limit

For technical and project documentation (README, CHANGELOG, OpenAPI, API docs, setup guides), use the `documentation` skill. If it cannot be loaded, write for a reader with zero context: state what the thing does, how to set it up, and how to verify it works.

## Brand Voice Guidelines

- Define tone: professional, casual, technical, friendly, authoritative
- Define words to use and words to avoid
- Define sentence length preference (short, medium, varied)
- Include examples of on-brand and off-brand phrasing

## Hard Rules

- **No false or unverifiable claims.** If you cannot cite a source, rewrite the claim. False claims destroy trust and can create legal exposure.
- **No unexplained jargon** unless the audience is technical. Every unexplained term is a lost conversion in marketing copy.
- **No clickbait headlines.** The headline must deliver what it promises. Short-term clicks do not survive a misled reader.
- **No plagiarism.** Attribute and link sources. Duplicate content damages reputation and search ranking.
- **Every piece has a target audience and a goal.** Content for "everyone" resonates with no one and cannot be evaluated.

## Verification checklist

```markdown
- [ ] One specific reader and one measurable goal stated
- [ ] Headline delivers on its promise
- [ ] Claims are sourced or removed
- [ ] Jargon explained for the chosen audience
- [ ] Voice matches the brand guidelines
- [ ] CTA names the next action and value
```
